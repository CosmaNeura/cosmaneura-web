# Skill: product-marketing (Cosmas)

Use when positioning, ICP, messaging pillars, or product truth need updating.

1. Open `product-marketing.md`.
2. If OPEN CONFLICTS remain, list them and stop.
3. Propose edits as a diff of sections; do not silently resolve conflicts.
4. Keep settled live-site facts intact unless the founder changes them.
5. Output: updated section text + changelog line for the doc.
