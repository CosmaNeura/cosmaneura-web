# Skill: copywriting (Cosmas)

Use when drafting or rewriting marketing copy.

1. Read `product-marketing.md`.
2. Write concrete workflow copy; avoid platform hype and “AI magic.”
3. Allowed proof shape: BAA with Cosmaneura Inc; self-attested HIPAA; not SOC 2.
4. Forbidden: claim submission, EHR write-back, NPI-at-signup, credential gates, SOC 2.
5. Preserve door/channel attribution.
6. Output: draft blocks mapped to page sections; mark assumptions.
